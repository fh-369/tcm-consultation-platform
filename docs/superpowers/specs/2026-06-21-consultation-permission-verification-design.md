# 问诊权限与异常验证设计

## 所属阶段

本功能属于产品完善总路线第 5 阶段“问诊详情与处理流程”的最后一个小阶段。

## 权限边界

- 患者只能创建和读取自己的问诊。
- 医生只能访问医生专用接口，并且只能处理分配给自己的问诊。
- 管理员只能进行平台调度，不能冒充医生回复问诊。
- 未审核、停用或没有科室的医生不能访问问诊池或处理问诊。
- 已完成问诊、非法状态流转和空回复继续返回明确业务错误。

## HTTP 错误语义

- `401 Unauthorized`：没有有效登录身份，包括未携带令牌、令牌失效或令牌无法识别。
- `403 Forbidden`：身份有效，但当前角色无权访问目标接口。
- `400 Bad Request`：业务规则不允许，例如处理他人问诊、非法状态流转。

## 前端行为

- 收到 `401` 时清理登录状态、提示登录过期并跳转登录页。
- 收到 `403` 时保留当前登录状态，提示“当前账号无权执行此操作”。
- 业务 `400` 继续展示后端返回的具体原因。

## 本阶段不包含

- 新增角色或细粒度权限配置页面。
- 审计日志系统。
- 第 6 阶段后台内容管理。
