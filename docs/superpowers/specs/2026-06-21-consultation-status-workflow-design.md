# 问诊接诊与状态流转设计

## 所属阶段

本功能属于产品完善总路线第 5 阶段“问诊详情与处理流程”的第二个小阶段。

## 状态规则

- `待接诊 → 接诊中`：医生点击“开始接诊”，不要求填写回复。
- `接诊中 → 接诊中`：医生追加一条非空回复。
- `接诊中 → 已完成`：医生填写本次回复后完成问诊。
- 禁止 `待接诊 → 已完成`、`接诊中 → 待接诊` 和任何从 `已完成` 发起的修改。
- 状态与回复更新继续写入问诊处理时间线。

## 页面交互

- 待接诊问诊只显示“开始接诊”按钮。
- 接诊中问诊显示空白回复输入框、“保存回复”和“完成问诊”按钮。
- 已完成问诊只读展示详情与处理时间线。
- 回复输入框每次保存后清空，避免把上一条回复误当成新记录。

## 移除随访业务

- 删除医生端随访时间输入和时间线中的随访展示。
- 删除患者端随访展示。
- 后端请求、实体和处理逻辑不再读写随访时间。
- 新建数据库结构不再包含随访字段。
- 已有本地数据库列暂时保留但不再使用，避免破坏性删除数据。

## 本阶段不包含

- 患者追加追问。
- 医生撤销完成状态。
- 消息通知、短信或站内提醒。
- 后台内容管理和统计优化。
