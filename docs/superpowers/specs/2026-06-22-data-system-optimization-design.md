# 数据与系统优化设计

## 目标

让管理员和医生获得符合各自权限范围的真实统计数据，升级管理员问诊导出，并统一后台页面的错误与操作反馈。

## 数据概览

- 管理员查看平台问诊状态、紧急度、趋势、科室分布、医生负载、注册患者、启用医生、已发布文章和药膳数量。
- 医生只查看分配给自己的问诊状态、紧急度和趋势，不读取平台全量统计。
- 日、周、月趋势继续使用同一接口，通过登录角色自动限制数据范围。

## 数据导出

- 仅管理员可以访问导出接口和页面。
- 支持日期范围、状态、紧急度、科室和医生筛选。
- 前端先查询匹配数量，数量为零时禁用导出。
- CSV 增加科室、接诊医生和分配时间字段。
- 日期范围包含结束日期当天。

## 权限与反馈

- 未登录统一返回 401，角色不匹配统一返回 403。
- 医生不能访问平台导出、人员管理、内容管理和管理员调度。
- 普通用户不能访问任何后台接口。
- 后台页面统一从响应体读取业务错误，区分网络错误、权限不足和登录失效。
- 加载失败页面提供重试入口，提交和导出期间禁止重复操作。

## 验收

1. 管理员与医生的数据概览范围不同且正确。
2. 导出筛选数量与 CSV 内容一致。
3. 无匹配记录时不下载空文件。
4. 权限错误返回明确中文信息。
5. 后端、前端测试及生产构建通过。
