# 智能自动分配设计

## 目标

用户提交具体科室问诊后，系统自动选择当前负载较低且等待分配时间更久的合格医生；自动分配失败不能影响问诊创建。

## 分配规则

- 综合咨询不自动分配，继续进入共享问诊池。
- 候选医生必须审核通过、账号启用并属于问诊科室。
- 负载为医生名下“待接诊 + 接诊中”问诊数量。
- 优先选择负载最少者。
- 负载相同时，从未获得过问诊者优先。
- 否则选择 `assigned_at` 最早的医生，再按医生资料 ID 升序。
- 不设置接诊容量上限。
- 不实现排班、值班状态和排班日历。

## 数据规则

- `consultations.assigned_at` 记录本次分配或认领发生时间。
- 自动分配、管理员分配和医生认领时写入当前时间。
- 取消分配和转科时清空。
- 历史问诊不回填，空值自然表示尚无可用分配时间。

## 异常处理

- 没有合格医生时，问诊保持未分配并正常创建。
- 自动分配查询或更新异常时记录警告日志，仍返回已创建问诊。
- 管理员手动分配和医生认领继续保持明确失败反馈。

## 验收

- 具体科室问诊自动分配给负载最少的合格医生。
- 负载相同时遵循从未分配、最久未分配、医生 ID 的稳定顺序。
- 综合咨询、无可用医生和自动分配异常均不阻断创建。
- 手动分配、认领、取消分配和转科正确维护 `assigned_at`。
