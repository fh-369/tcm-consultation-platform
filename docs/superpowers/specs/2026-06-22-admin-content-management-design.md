# 后台内容管理设计

## 目标

将现有通用表格和原始文本框升级为管理员可正式使用的养生文章、药膳和封面管理闭环，同时保证患者端只能读取已发布内容。

## 管理边界

- 仅管理员可以新建、编辑、发布、取消发布和删除内容。
- 医生和普通用户不进入后台内容管理。
- 本阶段不改造患者端文章与药膳详情页的整体视觉。
- 本阶段不包含统计、导出和角色权限体系重构。

## 页面结构

后台继续保留“养生文章”和“药膳管理”两个菜单，共用列表、筛选、分页、发布状态和操作反馈。

编辑操作改为宽抽屉：

- 文章表单包含标题、分类、摘要、Markdown 正文、日常提示和封面。
- 药膳表单包含名称、季节、体质、适合人群、摘要、食材、步骤和封面。
- 文章正文提供编辑与预览双栏。
- 页面提供“保存草稿”和“保存并发布”两个明确动作。

## 数据与接口

- 新增文章和药膳请求 DTO，使用 Jakarta Validation 统一校验。
- 新增独立发布状态接口，避免为了发布而提交整份正文。
- 新增管理员封面上传接口，文件保存到本机可配置目录，并通过 `/uploads/content/**` 公开读取。
- 上传只接受 JPEG、PNG 和 WebP，单文件最大 5 MB。
- “移除封面”只清除内容记录中的图片地址，不物理删除历史文件。
- 文章分类为空时继续由后端根据内容推断。
- 药膳季节和体质使用统一枚举值，避免产生重复筛选项。

## 错误与状态

- 字段错误显示具体中文提示。
- 上传格式、大小和空文件错误单独提示。
- 保存期间禁用重复提交。
- 列表包含加载、空数据和接口失败状态。
- 删除保留二次确认。

## 验收

1. 管理员可以完成文章和药膳的新增、编辑、发布、取消发布及删除。
2. 草稿不出现在患者端，发布后可以读取。
3. 封面可以上传、预览、更换和移除引用。
4. Markdown 正文可以在后台预览，保存后患者端正常渲染。
5. 搜索、分类或季节、体质、发布状态和分页工作正常。
6. 后端测试、前端测试和前端生产构建全部通过。
