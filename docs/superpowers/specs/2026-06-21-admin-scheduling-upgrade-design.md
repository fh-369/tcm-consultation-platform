# 管理员问诊调度升级设计

## 目标

强化管理员问诊调度的科室与医生约束，避免问诊科室和负责医生不一致。

## 业务规则

- 普通科室问诊只能分配给同科室、已审核且启用的医生。
- 综合咨询可以分配给任意科室中已审核且启用的医生。
- 问诊转科时自动解除原医生，状态恢复为“待接诊”。
- 已完成问诊不能转科或重新分配。
- 转科后，原医生的“我的问诊”不再显示该记录，新科室问诊池可以看到该记录。

## 页面交互

- 保留现有表格、筛选栏和调度抽屉。
- 调度抽屉中的医生列表根据当前问诊科室实时过滤。
- 医生名称后展示所属科室。
- 转科前显示确认提示，明确说明会解除原医生并恢复待接诊。
- 转科成功后清空当前负责医生展示和医生选择值。

## 本阶段不包含

- 自动分配与排班。
- 转诊历史和操作审计。
- 批量调度。
- 医生工作台结构调整。

## 验收

- 同科室医生可以分配，跨科室医生被后端拒绝。
- 综合咨询可以分配给任意合格医生。
- 转科后医生为空且状态为待接诊。
- 已完成问诊不能转科或重新分配。
- 后端测试、前端测试和生产构建通过。
